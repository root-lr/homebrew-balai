# Homebrew tap for Balai

[Balai](https://github.com/root-lr/Balai) is a free, open-source Mac cleaner.

```bash
brew install --cask root-lr/balai/balai
```

Update with `brew upgrade --cask balai`, remove with `brew uninstall --cask balai` (add `--zap` to also remove its preferences).

This tap is updated automatically by Balai's release workflow: please open issues and pull requests in the [main repository](https://github.com/root-lr/Balai).
